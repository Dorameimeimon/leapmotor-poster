## 推送网络问题突破（重要）
- 现象：多次 `git -c http.version=HTTP/1.1 push origin main` 均返回 `CONNECT tunnel failed, response 502`
- 原因：环境变量 HTTPS_PROXY/HTTP_PROXY 指向 http://127.0.0.1:50768，该本地代理隧道返回 502
- **解决方案**：绕过代理直连推送，命令：
  `git -c http.proxy= -c https.proxy= push origin main`
  本次用此命令一次成功（3f6b92e..80f30c6 main -> main）
- 输出中的 `failed to store: 100001` 只是本地凭据缓存提示，不影响推送结果
- **结论：今后 502 时优先尝试清空代理直连，而不是反复重试**

## UI 按钮造型再升级（10/16 第四次，53ca550）
- 背景：用户连续三次反馈"不像按钮"（白底描边 → 实心蓝渐变 → 立体渐变均未过关），根因是缺少"实体按键"的立体语言
- 最终方案（.filter-btn 重写为**胶囊立体按键**）：
  - `border-radius: 999px` 胶囊形 + `border: 1px solid #1e4a7d` 深色描边
  - **深色底边 bevel**：`box-shadow: 0 2px 0 #1e4a7d`（实体按键最关键的视觉线索）+ 外投影 + inset 高光
  - hover：`translateY(-1px)` 上浮 + 底边加厚至 3px + 投影增强
  - active：`translateY(1px)` 下沉、底边归零（按下感）
  - 激活态同款立体处理（红 #c62828 + 深红底边 #8e1414）
  - `font-family: inherit` 防字体回退
- 数据窗口不变（10/09–10/15, 77%/72）；已推送，线上 Pages 已生效（Pages 有 ~10s 构建延迟，抓取需带 cache-bust 参数）
- **经验**：判断线上是否生效不能只看一次 curl，GitHub Pages 存在构建延迟；验证时加 `?v=<timestamp>` 破缓存
